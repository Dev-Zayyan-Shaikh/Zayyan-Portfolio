01 / Concept

Resolving Phase Separation Hazards in Ethanol-Blended Fuels.

Technical Summary:

  • Dual Sensor Fusion (Optical & Dielectric)
  • Automatic Diaphragm Pump Extraction
  • Offline-Capable PWA hosted on microcontrollers
  • Live WebSocket canvas gauges & telemetry

The Environmental & Engineering Problem

Modern fuels contain a substantial portion of ethanol (E10, E20, E85). When water ingress occurs in storage tanks—due to condensation or leaking caps—the water readily binds with ethanol. Since this water-ethanol mixture is denser than pure gasoline, it separates out of solution and sinks, forming a highly corrosive, water-logged bottom layer ("phase separation").

If this contaminated boundary layer is drawn into engine systems, it damages fuel injectors, corrodes cylinder walls, and leads to catastrophic engine failure. Manual testing is sporadic, labor-intensive, and often detects water ingress only after damage has occurred.

The FuelGuard Edge-Computing Solution

FuelGuard solves this problem directly at the storage level. Combining optical refraction (LM393) and electrical dielectric metrics normalized for temperature, the system monitors fluid properties at the tank base. An ESP-based microcontroller detects boundary shifts in real time. Upon boundary detection, the edge node energizes a 12V diaphragm pump to draw out the corrosive bottom ethanol-water phase, returning the fuel tank to a safe stable state without manual intervention.

01 / Sensor Acquisition Layer

Dual-Sensor Fusion Array

To accurately spot the boundary boundary formation, FuelGuard relies on two physical properties: optical refraction and electrical permittivity. A modified optical sensor (LM393 photodiode) registers boundary light scattering, while a custom dielectric cell registers electrical conductance changes. Temperature readings from an NTC thermistor normalize the sensor values to eliminate fluid-density changes caused by thermal shifts.

02 / Edge Actuators

Automated ESP Extraction

The microcontroller acts as an edge controller. Once the sensor fusion algorithm synthesizes an active phase separation condition, the ESP node sends an electrical trigger to a high-current relay. This energizes a 12V diaphragm pump to draw out the dense bottom ethanol-water layer, dumping it in a waste container and automatically calculating the volumetric extraction ratio.

03 / Mobile Client interface

Embedded PWA Host

Industrial monitoring is often dependent on centralized servers. FuelGuard acts autonomously: it spins up a local Wi-Fi Access Point (AP) and hosts an offline-capable Progressive Web App (PWA) directly from its local flash filesystem (SPIFFS/LittleFS). Users connect directly to the ESP Access Point using their phones and interact with live Canvas charts, toast alerts, and manual pump override interlocks.

06 / Engineering Details

Engineering Challenges & Resolutions

1

Sensor Signal Drift & Temperature Interference

Challenge: The electrical conductance/dielectric voltage of the custom fluid cell shifted significantly under changing temperature profiles, causing false phase boundary triggers in warm conditions.

Resolution: Formulated an interpolation calibration table using analog NTC thermistor feedback. The microcontroller normalizes electrical values in real time to match standard 20°C profiles before synthesizing boundary decisions.

2

Multi-Phase Boundary Calibration

Challenge: Refraction properties differ across varying ethanol levels (E10, E20, E85), making a single optical static threshold ineffective at detecting phase boundaries.

Resolution: Programmed an adaptive calibration profile index stored in local EEPROM flash. The microcontroller performs a baseline self-calibration sweep on startup to establish custom threshold ratios.

3

Offline PWA Service Workers on Microcontrollers

Challenge: Storing and serving complex libraries from the extremely limited SPIFFS storage on an ESP8266 triggers network bottlenecks and lag during initial phone syncs.

Resolution: Developed the UI on vanilla code, avoiding external framework scripts. Compressed assets via gzip compression and coded service-worker caches to serve resources locally, bringing boot load to under 150ms.

Conclusion: FuelGuard demonstrates that localized, safety-critical fluid separation problems can be resolved efficiently at the edge. By fusing optical and dielectric sensor profiles onto low-cost ESP nodes and serving offline PWAs directly, the platform represents a resilient, autonomous approach to fuel asset security.
